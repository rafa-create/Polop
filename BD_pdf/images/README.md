## Important — binaires

Les PNG générés par l'outil d'image de la session ChatGPT ne sont pas encore stockés dans ce dépôt : le connecteur GitHub actif ne fournit pas d'action acceptant directement un fichier PNG local comme entrée. Il ne faut donc pas considérer la présence de ce manifeste comme la présence des binaires.

Aucune tentative rejetée ou autre image ressemblante ne doit remplacer silencieusement une image déjà validée. Si un original validé n'est plus récupérable byte-for-byte, son cas doit être explicitement signalé avant toute substitution ou régénération.
