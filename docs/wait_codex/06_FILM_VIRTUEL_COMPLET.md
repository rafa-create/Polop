# Film virtuel complet

## Éléments encore à construire

- A0 : anneau sous l'eau → rivière → vallée → montagne → famille ;
- comportement complet de l'anneau ;
- mousqueton visible ;
- événements naturels réversibles ;
- lumière de travail suffisamment lisible ;
- musique / son temporaire ;
- jeu minimum nécessaire ;
- transitions normales / inversées du plan-séquence ;
- final suffisamment lisible dans la grotte.

## But

Passer d'un blockout de vérité/trajectoires à un film virtuel visionnable comme un spectateur.

## Critères

Le montage doit pouvoir être regardé :
1. naïvement ;
2. comme puzzle ;
3. en audit causal.

La préviz n'est pas verrouillée tant que les trois lectures ne sont pas acceptables.

## Dépendances

À faire après :

- vérité physique anneau/mousqueton ;
- personnages fiables ;
- contrôles caméra de base.
