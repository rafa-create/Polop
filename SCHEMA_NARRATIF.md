## ACTE 2 : LA TEMPÊTE (17H05 - 17H40)

### PAGE 2 — 17H05 à 17H15 : L'Avertissement

```
             PROGRESSION DE LA MENACE
             
Bruit lointain → Silhouette → Appel → Tir → Fuite

     Thomas comprend :
     "Quelqu'un sait qui je suis"
     "Quelqu'un connaît Léa"
```

**La tension monte :** 3 indicateurs
1. Le bruit (environnement)
2. L'appel (connaissance personnelle)
3. Le tir (danger réel)

## Questions Éternelles

```
1️⃣  Qui a créé la machine ?
    → Le scientifique, mais pas pourquoi pour Thomas

2️⃣  Pourquoi Thomas specifically ?
    → Parce qu'il aimerait Léa plus que tout

3️⃣  Y a-t-il un moyen de sortir ?
    → Non. La boucle est fermée.

4️⃣  Éva & Léa le sauront-elles ?
    → Non. Jamais. Elles vivront heureuses dans l'ignorance.

5️⃣  Combien de fois Thomas revivra-t-il ça ?
    → Éternellement. À chaque fois qu'il rentre.

6️⃣  C'est quoi le "vrai" message du film ?
    → L'amour qu'on ne peut pas exprimer
    → Le sacrifice qu'on cache
    → La beauté de souffrir pour ceux qu'on aime
```
