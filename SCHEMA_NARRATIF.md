Caméra omnisciente — trajectoires & transitions

0. OBJECTIF DU DOCUMENT

Ce document ne constitue pas encore un découpage technique.

Il sert à déterminer :

* où circule la caméra ;
* quels espaces elle doit relier ;
* quels personnages elle accompagne ;
* quand elle doit abandonner un personnage pour en révéler un autre ;
* où peuvent se produire les transitions ;
* comment le même espace peut être réinterprété pendant l’inversion ;
* si la géographie générale permet réellement un plan-séquence.

Pas encore défini

* focale ;
* caméra exacte ;
* stabilisation ;
* drone ;
* vitesse ;
* hauteur précise ;
* VFX définitifs ;
* nombre de transitions cachées ;
* durée exacte de chaque mouvement.

⸻

1. PRINCIPE DE CAMÉRA

La caméra n’est pas attachée à Thomas.

Elle est omnisciente.

Elle peut :

* accompagner Thomas ;
* quitter Thomas ;
* observer Éva et Léa ;
* anticiper un déplacement ;
* révéler un élément avant que les personnages ne le remarquent ;
* traverser un espace pendant qu’un événement se produit ailleurs ;
* revenir plus tard dans un lieu déjà vu.

La caméra doit donner l’impression qu’elle connaît l’espace avant les personnages.

Présenter la montagne avant de présenter le mystère.

12. A9 — 17:50 : SÉPARATION

Thomas regarde sa montre.

Il prend quelques secondes d’avance.

Dialogue :

« Je vais regarder un truc. »

Transition essentielle

Au lieu de couper vers Éva et Léa, la caméra peut :

1. suivre Thomas ;
2. le laisser entrer dans le chemin secondaire ;
3. ralentir ;
4. regarder momentanément vers le chemin principal ;
5. retrouver Éva et Léa plus loin.

Cela permet de faire sentir que les deux trajectoires existent simultanément dans le même espace.

32. TRANSITIONS PRIORITAIRES À TESTER

T1 — PERSONNAGE → PAYSAGE

Thomas entre dans le cadre.

La caméra le suit.

Il sort.

Le paysage reste.

Transition naturelle.

⸻

T2 — ROCHER COMME ÉCRAN

Un rocher passe entièrement devant l’objectif.

Il masque le cadre.

Lorsqu’il le quitte :

nouvelle position.

Cette transition pourra être extrêmement utile pour masquer un déplacement de caméra ou un changement technique.

⸻

T3 — PIVOT SUR LE MOUVEMENT

La caméra accompagne un personnage.

Le personnage tourne.

La caméra tourne avec lui.

Le mouvement permet de révéler un autre axe spatial.

⸻

T4 — OBJET COMME TRANSITION

Montre.

Anneau.

Nœud.

Pierre.

Ces objets peuvent devenir des points de raccord visuel entre A et B.

⸻

T5 — TRANSITION SONORE

La caméra quitte un personnage.

Le son d’un autre personnage existe avant son apparition.

Puis la caméra le découvre.

Très utile pour :

* Éva ;
* Léa ;
* appels ;
* recherche.

⸻

33. RÈGLE D’OR

Aucune transition ne doit avoir pour fonction :

« cacher un problème de scénario ».

Les transitions doivent servir :

la géographie + la perception + la causalité.

Si une transition nécessite un énorme artifice uniquement pour faire fonctionner la continuité, cela signifie probablement que la géographie doit être corrigée.

⸻

34. CE QU’IL FAUT TESTER AVANT LE DÉCOUPAGE TECHNIQUE

TEST 1 — Géographie

Peut-on relier :

chemin principal → creux → pont → chemin secondaire → grotte

sans contradiction ?

TEST 2 — Éva/Léa

Peuvent-elles chercher Thomas puis descendre sans croiser Thomas inversé ?

TEST 3 — Thomas inversé

Peut-il parcourir la géographie inverse sans créer de rencontre impossible ?

TEST 4 — Pont

Le même pont peut-il être filmé dans A puis retrouvé naturellement en B ?

TEST 5 — 17:00

La caméra peut-elle revenir exactement au point narratif de départ sans avoir besoin de montrer une deuxième fois toute la scène ?

TEST 6 — Transitions

Chaque passage important peut-il être réalisé :

* par déplacement ;
* par élément du décor ;
* par personnage ;
* par son ;
* ou par VFX discret ?

36. HYPOTHÈSE DE TRAVAIL

À ce stade, le plan-séquence paraît structurellement compatible avec le récit.

Mais la question n’est pas encore :

« Peut-on techniquement faire un plan-séquence ? »

La vraie question est :

« Peut-on faire circuler une caméra dans cette géographie sans qu’elle révèle trop tôt le mécanisme de la boucle ? »

C’est ce que le prochain schéma doit vérifier.
